## Public repositories

### Writing and reference

- [Cheatsheets](https://john-cd.github.io/cheatsheets/) — Technical reference material and code examples. Browse the [source repository](https://github.com/john-cd/cheatsheets).
- [The Rust How-To Book](https://john-cd.com/rust_howto/) — A collection of summaries and practical recipes for the Rust language and ecosystem. Browse the [source repository](https://github.com/john-cd/rust_howto).
- [mdbook-utils](https://github.com/john-cd/mdbook-utils) — Rust command-line tools for managing Markdown links, reference definitions, code examples, and mdBook workflows.

### Developer tools

- [Rust workspace starter](https://github.com/john-cd/rust_template) — A `cargo-generate` template for Rust workspaces with a library, CLI, developer tools, and shared project configuration.
- [Rust GitHub Action](https://github.com/john-cd/rust_github_action) — A reusable action that builds a Rust application and packages the executable in a small Docker image.
- [Rust action test project](https://github.com/john-cd/test_github_action) — An example repository for exercising the Rust GitHub Action.
